# 🌱 Smart Irrigation System

## 📌 Project Overview

The Smart Irrigation System is a web application developed using Python, Flask, HTML, and CSS. It helps farmers estimate water requirements for crops based on soil type, crop type, temperature, and weather conditions.

The application fetches live weather data and automatically adjusts irrigation recommendations when rain is detected.

---

## 🚀 Features

* Soil-based water calculation
* Crop-based water calculation
* Live weather data integration
* Automatic temperature detection
* Rain-aware irrigation recommendations
* Prediction history tracking
* User-friendly web interface

---

## 🛠 Technologies Used

* Python
* Flask
* HTML
* CSS
* Requests Library
* Git & GitHub

---

## 📊 Working

1. User selects soil type.
2. User selects crop type.
3. User enters city name.
4. System fetches live weather information.
5. Temperature and weather conditions are analyzed.
6. Water recommendation is generated.
7. Water amount is reduced automatically if rain is detected.
